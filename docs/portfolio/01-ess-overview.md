# ESS Overview

> 02 / Portfolio reference

The Engineered Semantic Substrate (ESS) is the foundation under every working surface in this portfolio. It is four spec-like layers, each owning a distinct axis of meaning:

- **TCCP** (type-theoretic): what kinds of things exist — types, ontologies, categories.
- **EKRP** (module-theoretic): how types become artifacts — modules, packs, contracts, signatures.
- **MINC** (algebra-theoretic): how artifacts compose — notation, operations, monoids, proofs.
- **Sigil** (grammar-theoretic): how artifacts are inscribed — grammar, fallback, conformance.

## Bounded features

The four substrates compose into a current total of 663 bounded features. Each feature belongs to exactly one substrate; cross-substrate features are composed at named seams (four primary, two absorbed-historical). The feature set is append-only: adding a feature requires a proposal and a review.

## Question framework

On top of the substrates sit 64 lenses, 64 input types, and 40 composition primitives. A question instance is the triple: lens + input type + primitive composition. The framework is closed; new entries require a formal amendment.

## Why it matters

Every artifact, page, and claim in this portfolio traces back through the ESS to its source. The substrates are not a framework you install; they are a vocabulary you use to make your work inspectable.
