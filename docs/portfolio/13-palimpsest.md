# Palimpsest

> 13 / Portfolio reference (concept, not deployed)

Palimpsest: The Last Archivist is a concept exploring layered knowledge representation and the return route — the idea that every surface is a projection over a source, and every projection can be read back to the source it was derived from.

## What it is

A narrative concept: the last archivist in a world where knowledge is layered, where each layer is a projection, and where the return route (the receipt) is the only way back to the source. The concept tests the bounded vocabulary's projection and receipt terms as narrative structure.

## What it is not

Palimpsest is not a deployed product, a scheduled release, or a public artifact. It is a proposal that tests the working surface from a narrative angle.

## Where it fits

Palimpsest is one of two concept surfaces in this portfolio (the other is Exocore: The Game). Both are proposals, not deployed systems.

## Status

Proposal. Not deployed. Not scheduled. The concept exists in the Hub as a research direction.
