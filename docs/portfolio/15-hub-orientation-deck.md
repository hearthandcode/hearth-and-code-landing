# Hub Orientation Deck (r007)

> 15 / Portfolio reference

The r007 Ember Circuit orientation deck is a 32-slide presentation that introduces the full working surface. It is the source for this portfolio's visual language and content structure.

## What the deck covers

- **Slides 1-4**: the ordinary world — what is governed, why it matters.
- **Slides 5-14**: the four ESS substrates (TCCP, EKRP, MINC, Sigil), the integration layer, and the 663 bounded features.
- **Slides 15-19**: the Agentic OS, the agent host, the memory layer, the workspace, and the Pi extension.
- **Slides 20-22**: three tests — bounded review, corpus review, and implementation campaign.
- **Slide 23**: Exocore Sigil — the inscription surface and the OUT.sigil artifacts.
- **Slides 24-28**: the charter, Core32, three models, the bounded vocabulary, and the release pattern.
- **Slides 29-32**: the platform, the memory hoard, the honest limit, and the three routes.

## Visual language

The deck uses the Ember Circuit design system: field-950 background, ember-500 accent, cream-bright text, Georgia for display, system-ui for body, SF Mono for code. The layout grammar includes cover, two-column, three-column, bento-grid, split-hero, endcap, step-list, comparison-rows, and timeline.

## Where it lives

The deck is a public-safe projection from the Hub's outreach project (0038). It is not a deployed product; it is a presentation surface.
