# Exocore: The Game

> 12 / Portfolio reference (concept, not deployed)

Exocore: The Game is a concept exploring the same bounded vocabulary, release pattern, and corpus-review process applied to play.

## What it is

A cognitive workbench game surface: the ESS as a game world, the Core32 fleet as playable characters, the release pattern as the game's action economy, and the bounded vocabulary as the game's claim system.

## What it is not

Exocore: The Game is not a deployed product. It is a proposal — a concept that explores whether the working surfaces can be inhabited as play. The game does not have a release date, a playable build, or a public artifact.

## Where it fits

The game is one of two concept surfaces in this portfolio (the other is Palimpsest). Both are proposals that test the working surface from a different angle: the game tests the ESS as a playable system; Palimpsest tests the knowledge representation as a narrative.

## Status

Proposal. Not deployed. Not scheduled. The concept exists in the Hub as a research direction; it does not appear on the public site as a product.
