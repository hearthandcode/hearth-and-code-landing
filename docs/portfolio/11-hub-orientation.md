# Hub Orientation

> 11 / Portfolio reference

The Hub is the knowledge substrate under every surface in this portfolio. It is a 16-wing structure with 256 workrooms, 32 Core32 profiles, 64 lenses, 64 input types, and 40 composition primitives.

## Structure

- **16 wings**: governance, research, intake, mechanism, operations, rendering, prose, knowledge, projects, community, skills, archive, ledger, program, archive, evaluation.
- **16 workrooms per wing**: 256 total. Each workroom owns a bounded feature or process.
- **32 Core32 profiles**: the agent fleet; each profile is a bounded role with an input type, output type, and falsifier.
- **64 lenses**: the comparison surfaces for bounded review.
- **64 input types**: the question surfaces; each carries a source binding.
- **40 composition primitives**: the rendering alphabet; 4 families (Capture, Structure, Compose, Reference).

## The bounded vocabulary

The Hub uses eight terms as its claim labels: source, evidence, inference, hypothesis, proposal, projection, receipt, unknown. No ninth term is permitted without a formal amendment.

## The release pattern

Every effect in the Hub requires a separate explicit human release. The agent does not self-authorize; the release names the effect, the target, and the scope.

## Where it lives

The Hub is a private knowledge system; this portfolio is its public-safe projection. No internal Hub paths, credentials, or unreleased work appear on this surface.
