# Agentic OS

> 07 / Portfolio reference

The Agentic OS is the OS-shaped surface for governed agent workflows. It is the thesis that the ESS, the Core32 fleet, and the release pattern compose into an operating system for agent work — not a kernel, not a scheduler, but a governance layer.

## What it is

- **Governed workflows**: every effect is named, sourced, released, and recorded.
- **Bounded vocabulary**: every claim uses one of eight labels (source, evidence, inference, hypothesis, proposal, projection, receipt, unknown).
- **Release pattern**: every action requires an explicit human release; the agent does not self-authorize.
- **Receipt trail**: every effect leaves a receipt; the receipt does not authorize the next action.

## What it is not

The Agentic OS is not a deployed operating system. It is the thesis that the ESS + Core32 + release pattern compose into a governance layer for agent work. The thesis is under active research.

## Status

Thesis, not deployment. The components (ESS, Core32, release pattern) are deployed individually; the OS-shaped composition is the research direction.
