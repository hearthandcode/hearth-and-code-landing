# Core32 Fleet

> 08 / Portfolio reference

Core32 is the fleet of thirty-two named specialist profiles. Each profile has a bounded role, an input type, an output type, and a falsifier — the condition under which the profile is mis-scoped.

## What the fleet is

- **32 profiles**: architectus, artifex, conceptor, ... periagogus (the thirty-second, the re-entry profile).
- **Each profile**: a bounded input contract, a bounded output contract, and a falsifier.
- **Not a roster**: the fleet is not a list of available agents; it is a set of bounded roles that the agent host can dispatch.
- **Not dynamic**: the fleet does not grow by discovery; new profiles require a formal amendment.

## How it works

The agent host selects a profile for a task. The profile's input contract defines what it accepts; the output contract defines what it produces; the falsifier defines when the profile is the wrong choice. The selection is a comparison, not a generation.

## Where it fits

Core32 is the agent side of the working surface. The ESS is the substrate; HCAN is the notation; Sigil is the inscription; Core32 is the workforce.
