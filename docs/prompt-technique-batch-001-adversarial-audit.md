## Pass 2 — alignment audit

### Structural and provenance checks that passed

- Exactly eight authored entries, matching vendored catalogue order #002–#009; each has four applied steps, four use-decision steps, and four limitations. `node --test scripts/methods-contract.test.mjs scripts/prompt-response-markdown.test.mjs`: **7 passed / 0 failed** in this audit.
- Each entry has two captured Pi turns, baseline and applied, using the same synthetic fact packet, declared `minimax-oauth/MiniMax-M3` route, no session and no tools. Stored prompt/response SHA-256 values match the public bytes (one explicitly redacted public response has a separate original digest). This proves record structure and current-byte integrity, **not** provider efficacy or independent execution attestation.
- `npx astro build`: **54 pages built** in this audit. It does not semantically validate the claims or prove accessibility. No full `npm run build`/Astro typecheck result is claimed here.
- The source candidate records inspected remain `review_status: unreviewed`, `verified: false`, `evaluation_status: not-evaluated`; public editorial status is independent of source admission. External primary studies have not been verified for this batch.

### Incomplete or misaligned seams

1. **Source-mechanism fidelity:** #003 fails; #004 loses stage stops; #009 loses the required digest field. #005's outcome criterion is a proposal, not a settled owner target.
2. **Four-section completeness:** exact counts pass, but some fourth 'when' points are generic exclusions rather than technique-specific anti-triggers. #007 omits check-time and not-run checks from its authored process. Section count alone does not certify instructional usefulness.
3. **Matched comparison validity:** identical source facts and provider route are recorded, but the applied prompt also adds task constraints and evaluation criteria not present in baseline (#005 most clearly). The pair illustrates a mechanism; it is **not** a controlled efficacy experiment. One sample per arm cannot establish reliability, transferability, or causal gain.
4. **Editorial findings are not digest-bound:** #006's stale note survived a retry. Each finding should bind to the specific sample response digests it evaluates; a changed response must invalidate the note until re-reviewed.
5. **Public output treatment:** entry #006's model-produced internal label was redacted and disclosed. The archived public copies are also redacted, so the original raw digest is not independently reproducible from committed bytes. That is a stated evidence limitation, not a clean pass.
6. **Reader accessibility/shareability:** `PromptCardSheet` is a portal `article`, not a modal dialog (`role="dialog"`/`aria-modal` absent); after opening, focus initially stays on the underlying tile. Escape handling exists, but focus containment and restoration are not evidenced. A selected technique has no stable direct deep link; `/methods/#prompt-lab` only reaches the section. These are next UI review seams, not substantive model results.
7. **Tone leakage:** some outputs add internal governance words or ritual framing to ordinary workplace tasks. These are model outputs rather than authored prompts, but the teaching surface needs a criterion for professional clarity, not just a blacklist of private names.
